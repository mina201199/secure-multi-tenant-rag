# 知序 Atlas：完整介面展示

2026-10-20，分支 `codex/workspace-demo`，基於 M2-01 版本模型。沿用 FastAPI、Jinja2、原生 CSS / JavaScript，沒有新增前端框架或外部 CDN。

## 開啟

```powershell
docker compose up --build -d
```

開啟 <http://127.0.0.1:8008/demo> 即可體驗，不需要密碼。右上方標示「互動展示／示範資料」。這個頁面不讀取 Session 或文件資料庫，不傳送檔案、不呼叫模型、不產生費用；所有變更只保存在頁面記憶體，重新整理即還原。

真實的 `/login`、`/documents` 與文件內容頁也套用新視覺，仍使用原本的 Session、CSRF、後端版本授權查詢。Demo 不能解鎖真實 API。公開資源只包含固定的虛構人物與文件。

## 可操作流程

| 畫面 | 展示操作 | 正式功能狀態 |
| --- | --- | --- |
| 文件知識庫 | 關鍵字 / 分類、收藏、清單 / 卡片、閱讀、封存 | 目前有效版本的授權閱讀已接後端；其他為展示 |
| 上傳與處理 | 選 PDF / TXT、建立私人佇列、模擬完成處理 | 沒有讀取或傳送所選檔案內容；解析與向量化待接入 |
| 閱讀權限 | 僅自己 / 本公司 / 同公司指定人員、a.reader 閱讀預覽 | 展示不寫入真實 ACL |
| 新增版本 | 修改示範正文、原有效版保持可用、完成後新版私人且 ACL 清空 | 正式版本寫入及處理 API 待接入 |
| 知識問答 | 三個固定問題、來源與版本、原文閱讀；證據不適用時拒答 | 預設回答，沒有模型呼叫；檔案變更 / 封存後舊回答失效 |
| 文件交接 | 提出申請、我的案件、主管情境審核、核准 / 拒絕 | 只改展示申請狀態；不移轉真實擁有權 |
| 歷史調閱 | 獨立授權範例與本次調閱紀錄 | 正式歷史授權 / 稽核待接入 |
| 成員管理 | 管理員情境的啟停確認 | 不改正式帳號、不增加角色或文件權限 |
| 用量與預算 | NT$300 預算、預留 / 結算與示範每日圖表 | 金額與用量皆為虛構；正式預算閘門待接入 |

一般文件頁不提供歷史回查。主管審核情境不顯示檔名、摘要或內容；歷史版本以獨立頁面展示。

## 驗證

- 後端整合測試：`docker compose --profile test run --build --rm tests`，59 passed，1 個既有 TestClient 棄用警告。
- JavaScript 語法：`node --check app/static/workspace.js`；差異格式：`git diff --check`。
- 實際 Chromium 操作：搜尋 / 空結果 / 卡片切換、權限預覽 / 儲存、問答 / 原文引用、新版排程 / 完成 / 私人預設、舊證據失效、主管資訊最小化 / 審核、成員狀態、歷史紀錄跨畫面保留、20 日用量圖表。
- 邊界操作：所有接收人停用、所有有效文件封存時，交接顯示無法提出；選擇虛構 TXT 後可加入展示佇列。
- 視覺檢查：1440px 桌面、390px 手機與登入頁；手機頁面寬度 390px，沒有整頁橫向溢出，表格可單獨橫向滑動。
- 靜態審查發現的過期引用、交接空選項及歷史紀錄遺失已修正，再以實際瀏覽器操作確認。

尚未完成的後端任務仍依 README 的 M2 / M3 / M4 清單驗收，不因展示頁可點選而勾選。
